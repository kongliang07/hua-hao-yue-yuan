# 🌕 花好月圆｜中秋节文化与祝福

> 以现代网页设计呈现中华传统文化，带领访客认识中秋节的由来、历史、传统习俗、节日美食与团圆祝福。

## 一、项目简介

「花好月圆｜中秋节文化与祝福」是一个以中国传统节日——中秋节为主题的网站。

本网站结合中秋文化介绍、节日倒数、多语言切换、节日影片与祝福语互动等内容，希望通过清晰的网页布局、温暖的节日视觉设计和简单易用的互动功能，让访客在浏览网站的过程中，认识中秋节的文化背景，了解传统习俗背后的意义，并感受中秋节所代表的团圆、思念、感恩与分享精神。

网站以酒红色、暖金色和米白色为主要视觉方向，结合具有中国传统节日气氛的设计元素，让传统文化以更现代、亲切和容易理解的方式呈现。

## 二、为什么制作这个中秋节网站？

中秋节是中华传统文化中具有代表性的节日之一。每逢农历八月十五，许多人会赏月、吃月饼、提灯笼，并与家人朋友团聚。然而，中秋节的意义并不只是庆祝节日或享用美食，它也包含了丰富的历史故事、传统习俗和人与人之间的情感。

我制作这个网站，是希望让更多人有机会认识中秋节，了解它的由来、文化传承和庆祝方式。

在现代生活中，人们可以通过互联网接触不同的文化知识。因此，我希望把中秋节的相关内容整理在一个容易浏览的网站中，让访客不用花很多时间寻找资料，也能够从不同角度认识这个传统节日。

制作这个网站的主要目的包括：

- **认识传统文化：** 介绍中秋节的由来、历史故事和文化背景，让访客了解节日如何逐渐发展成为今天熟悉的传统节日。
- **理解团圆的意义：** 通过节日介绍与相关内容，说明中秋节为什么经常与家庭团聚、亲友相聚和思念联系在一起。
- **了解传统习俗：** 介绍赏月、吃月饼、提灯笼和团圆家宴等活动，让访客认识中秋节常见的庆祝方式。
- **分享节日祝福：** 提供不同语言的中秋祝福语，让访客能够把节日心意传递给家人、朋友和重要的人。
- **结合文化与科技：** 运用 HTML、CSS 和 JavaScript 制作互动网页，让传统文化内容以现代数字形式呈现。
- **促进文化传承：** 希望学生、家庭以及对中华文化感兴趣的人，都能通过这个网站认识并分享中秋节的文化价值。

我希望这个网站不只是一个介绍节日的网页，也能成为一个让人学习文化、感受节日气氛和传递祝福的小平台。

## 三、网站里面有什么？

### 1. 首页｜认识中秋节

首页是访客进入网站后首先看到的部分，主要负责展示网站主题，并引导访客浏览其他内容。

首页采用中秋节主题的视觉设计，营造温暖、雅致的节日气氛，让访客能够快速了解网站的主题，并通过导航前往感兴趣的内容。

### 2. 中秋倒数｜迎接中秋佳节

倒数区域显示距离设定目标日期的剩余时间，包括：

- 天数
- 小时
- 分钟
- 秒数

倒数会持续更新，让访客直观地看到节日临近的时间变化。目标日期可以在 JavaScript 文件中调整。

### 3. 中秋由来｜了解节日故事

这一部分介绍中秋节相关的传统故事与文化背景，包括广为流传的嫦娥奔月、月宫和玉兔等传说。

通过这些故事，访客可以认识中秋文化中丰富的想象与象征，并进一步了解传统故事如何成为节日文化的一部分。

### 4. 为什么过中秋｜认识节日意义

中秋节的意义不只在于庆祝，也与人们的生活、情感和传统文化密切相关。

本部分从以下角度介绍中秋节的价值：

- **秋收与感恩：** 认识秋季收获与传统节庆之间的联系。
- **家庭团圆：** 了解中秋节为什么经常成为家人相聚、分享生活的时刻。
- **思念与祝福：** 通过赏月和送上祝福，表达对亲友的关心。
- **文化传承：** 了解传统节日如何通过家庭活动与社会习俗延续至今。

### 5. 中秋节做什么｜认识传统习俗

本部分介绍中秋节常见的庆祝活动，让访客更容易理解节日如何融入日常生活。

- **赏月：** 与家人朋友一起欣赏月亮，享受宁静温馨的相聚时光。
- **吃月饼：** 品尝不同口味的月饼，并分享节日祝福。
- **提灯笼与赏花灯：** 感受灯笼和花灯带来的传统节庆气氛。
- **团圆家宴：** 与家人一起用餐、交流近况，珍惜相聚的时间。

### 6. 中秋美食｜品尝节日的味道

中秋美食是节日文化的重要组成部分。本部分介绍不同类型的中秋食品，以及美食与家庭分享之间的联系。

网站涉及的内容包括：

- **广式月饼：** 认识薄皮、丰富馅料等常见特色。
- **冰皮月饼：** 了解具有不同外观与口感的月饼类型。
- **月饼与茶：** 感受品茶与分享月饼所营造的节日氛围。
- **团圆家宴：** 认识中秋节与家人聚餐之间的联系。

通过美食介绍，让访客了解中秋节不只是一个传统节日，也是一段能够通过味道与分享留下记忆的时光。

### 7. 中秋影片｜通过影音认识节日

网站设置了中秋主题影片区域，让访客可以通过影片进一步认识节日文化。

影片主题包括：

- 中秋节与团圆的意义
- 中秋故事与文化背景
- 玉兔与中秋传统
- 赏月、赏灯和传统习俗
- 月饼与中秋美食
- 中秋节相关的文化内容

访客可以点击影片封面，在网站的播放窗口中观看相关影片。影片播放依赖外部视频平台，可能受到网络状况、平台规则或地区限制影响。

### 8. 中秋祝福｜把心意送给重要的人

祝福区域让访客能够浏览和分享中秋节祝福语。

主要功能包括：

- **换一句祝福：** 切换并浏览不同的祝福内容。
- **复制祝福：** 复制当前显示的祝福语，方便分享。
- **多语言祝福：** 提供华语、英语和马来语内容。

这部分希望让访客不仅能认识中秋节，也能将团圆、关怀和祝福传递给身边的人。

## 四、网站主要功能

| 功能 | 功能说明 |
|---|---|
| 节日倒数 | 动态显示天、小时、分钟和秒数 |
| 多语言切换 | 支持华语、英语和马来语页面文字 |
| 影片播放 | 点击影片封面，在页面播放窗口中观看 |
| 祝福语切换 | 浏览不同的中秋祝福内容 |
| 复制祝福 | 复制当前祝福，方便发送和分享 |
| 响应式布局 | 根据电脑、平板或手机屏幕调整页面布局 |
| 手机导航 | 在较窄的屏幕上使用展开式导航菜单 |
| 页面分区导航 | 通过导航快速前往网站的不同内容区域 |

## 五、网站设计理念

本网站的设计围绕三个核心方向：**传统文化、清晰易读、简单互动**。

### 视觉设计

以酒红色、暖金色和米白色为主要配色方向，营造温暖、雅致且具有节日氛围的视觉体验。

### 内容布局

通过清晰的标题、导航和内容卡片，将历史、习俗、美食、影片和祝福等主题分开呈现，方便访客快速找到想了解的信息。

### 用户体验

使用清楚的文字、适当的间距和直观的按钮，让不同年龄层的访客都能轻松浏览网站。

### 现代网页体验

结合倒数计时、语言切换、影片播放和祝福复制等互动功能，让传统文化内容不只是静态阅读，也具有一定的参与感。

### 多设备适配

采用响应式网页设计，让网站在电脑、平板和手机等不同屏幕上都能尽可能保持清晰与易用。

## 六、使用的网页技术

本项目使用基础网页技术开发，不依赖大型前端框架。

- **HTML5：** 负责网页结构、标题、文字、导航和内容区域。
- **CSS3：** 负责网页配色、排版、卡片样式、响应式布局和视觉效果。
- **JavaScript：** 负责倒数计时、语言切换、影片播放交互、祝福切换和复制功能。
- **GitHub：** 用于存放项目文件与管理代码。
- **GitHub Pages：** 可用于发布静态网站，让其他人通过公开网址浏览。

本网站属于静态网站，目前不包含用户账号系统、服务器端程序或数据库。

## 七、项目文件结构

```text
中秋节网站/
├── index.html   # 网站结构与主要内容
├── style.css    # 网站样式与响应式布局
├── scrip.js     # 倒数、语言切换和互动功能
└── README.md    # 项目介绍与使用说明
```

请注意：网站目前使用的 JavaScript 文件名是 `scrip.js`。上传到 GitHub 时，请确保文件名与 `index.html` 中引用的路径一致。

## 八、如何运行网站？

1. 将 `index.html`、`style.css` 和 `scrip.js` 放在同一个文件夹中。
2. 使用浏览器打开 `index.html`，即可浏览网站。
3. 也可以使用 Visual Studio Code 搭配 Live Server，在本地启动网站进行测试。
4. 测试倒数、语言切换、影片播放和祝福复制等功能。
5. 如需加载外部影片和图片，请确保设备能够连接互联网。

## 九、如何发布到 GitHub Pages？

1. 将网站文件上传到 GitHub 仓库。
2. 打开仓库的 **Settings → Pages**。
3. 在发布设置中选择 **Deploy from a branch**。
4. 选择 `main` 分支与 `/(root)` 文件夹，然后保存。
5. 等待 GitHub Pages 完成发布，并从 Pages 页面查看网站网址。

发布前，请确认 `index.html` 位于发布目录的最上层，并检查 CSS、JavaScript、图片与影片链接是否正确。
