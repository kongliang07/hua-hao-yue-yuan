# 🌕 花好月圆｜中秋节网站

## 一、为什么我要制作这个网站？

我制作这个网站，是希望让更多人了解中秋节的由来、传统习俗和文化意义。

很多人知道中秋节要吃月饼、赏月和与家人团聚，但不一定了解这些习俗背后的意义。因此，我把中秋节的相关知识整理在一个网站里，让大家更容易认识中秋文化。

## 二、中秋节是什么？

中秋节是中华传统节日之一，日期为农历八月十五。它与赏月、月饼、家庭团聚等习俗密切相关。

中秋节主要代表三种意义：

- **团圆：** 与家人相聚，共享团圆时光。
- **思念：** 想念远方的家人和朋友。
- **传承：** 延续传统习俗，认识中华文化。

嫦娥奔月、玉兔和吴刚伐桂等传说，也为中秋节增添了丰富的文化色彩。

## 三、我的网站里面有什么？

### 1. 中秋节由来
介绍中秋节的文化背景与相关传说，让访客认识这个传统节日。

### 2. 为什么过中秋
解释中秋节与团圆、思念、感恩和家庭相聚之间的联系。

### 3. 中秋传统习俗
介绍赏月、吃月饼、提灯笼、赏花灯、团圆饭和家人相聚等活动。

### 4. 中秋美食
介绍广式月饼、冰皮月饼、月饼配茶和团圆家宴，让访客认识中秋饮食文化。

### 5. 中秋节倒数
显示距离设定的中秋节日期还有多少天、小时、分钟和秒数。

### 6. 中秋祝福
提供不同的中秋祝福语，可以更换和复制祝福，并分享给家人和朋友。

### 7. 多语言切换
提供华语、英语和马来语页面文字，方便不同语言背景的访客浏览。
