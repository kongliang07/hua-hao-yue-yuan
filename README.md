🌕 花好月圆｜中秋节网站

为什么我要做这个中秋节网站？

我制作这个中秋节网站，是希望让更多人简单、清楚地了解中秋节。

很多人知道中秋节会吃月饼、赏月、团圆，但不一定了解中秋节的由来、传统习俗和节日背后的意义。

所以，我把中秋节的重要内容整理在一个网站里，让访客不用到不同地方寻找资料，就可以直接了解中秋节。

这个网站主要希望做到三件事：

让人了解中秋节

让人认识中秋传统文化

让人感受到中秋节“团圆、思念、祝福”的意义

我的网站里面有什么？

1. 中秋节由来

介绍中秋节的文化背景和相关故事，让访客知道中秋节是怎么来的。

2. 为什么要过中秋

说明中秋节为什么和团圆、家人、思念和祝福有关系。

3. 中秋节做什么

介绍常见的中秋习俗，例如：

赏月

吃月饼

提灯笼

赏花灯

团圆饭

和家人聊天相聚

4. 中秋美食

介绍中秋节常见的食物，例如：

广式月饼

冰皮月饼

月饼配茶

团圆家宴

让访客了解中秋节不只是一个节日，也有属于它的饮食文化。

5. 中秋节影片

网站提供中秋主题影片，让访客通过影片进一步了解：

中秋团圆

月亮故事

玉兔

传统习俗

月饼

中秋文化

6. 中秋节倒数

网站有倒数功能，可以看到距离下一次中秋节还有：

天数、小时、分钟、秒数。

7. 中秋祝福

网站提供中秋祝福语，可以：

换一句祝福

复制祝福

分享给家人和朋友

同时提供华语、英语和马来语内容。
